Course

How LLMs work: concepts, code and tricks

A self-paced course built on the original research. Read the lessons here; run the matching notebooks on a laptop (CPU is enough). It ends with a small modern GPT trained from the pieces.

  • 1. Big picture — pipeline, training stages, generation
  • 2. Tokenization and BPE — byte-level BPE from scratch, vocabulary size, language costs
  • 3. Embeddings and a bigram baseline — lookup tables, counting vs gradient descent, Bengio's neural LM, GPT-2's embeddings
  • 4. Self-attention step by step — averaging to attention, Q/K/V, scaling, causal mask, multi-head, what GPT-2's heads do, tiny attention models
  • 5. The transformer block: residuals, RMSNorm, SwiGLU
  • 6. Training: AdamW, schedules, scaling laws
  • 7. Positional encodings: sinusoidal to RoPE
  • 8. Efficient attention: KV cache, GQA, FlashAttention
  • 9. Sampling and decoding, speculative decoding
  • 10. Quantization
  • 11. LoRA fine-tuning
  • 12. Alignment: RLHF and DPO
  • 13. Reasoning and RL
  • 14. Capstone: train the GPT
